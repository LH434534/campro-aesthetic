# campro-aesthetic

Visual and aesthetic layer of the [CamPro](https://github.com/LH434534/campro) camera stack: the same Android package (`com.thiairo.campro`), focused on rendering, resources and interface rather than capture.

## Contents

- `AndroidManifest.xml` — package and camera features
- `res/` — drawables, styles and themes
- `src/` — UI and presentation code
- `build/` — build configuration

## Stack

Java · Android SDK
